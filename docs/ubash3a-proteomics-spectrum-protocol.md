# Bounded PXD000376 spectrum reanalysis

This protocol is written before new public-spectrum scores. The first experiment is the complete `05BR2_nonNuclear_IOB` set in the separately timestamped [selection record](../config/ubash3a-proteomics-spectrum-selection.json): 14 raw files and 2,387,832,397 listed bytes. Pooled fractions and a repeat injection remain included and are not independent donors. The source describes naïve CD4 non-nuclear material; a naïve–memory or genotype comparison is outside this search.

## Database and measurements

Complete and checksum-lock the specified UniProtKB, GENCODE and contaminant references before candidate matching and final search-database construction. Include both conditional T29 products and all twenty preceding models. Deduplicate identical full protein sequences while retaining every source membership in a separate mapping. Preserve ambiguous residues and internal stop characters in the source record; explicitly report how the search engine handles these. I/L equivalence is enabled. Sequence sharing cannot establish a source RNA or allele.

Use the pinned Comet 2026.02.2 binary in ordinary FASTA-search mode with internal concatenated target–decoy competition. Its decoys reverse each peptide while retaining the digestion-terminal residue. Do not use an index with this internal-decoy setting. Check the four targets for collisions with background target/decoy sequences and preserve any collision as ambiguity. Exact parameter-file and database hashes must be recorded before the first real-data search.

Convert the complete raw files with the pinned ThermoRawFileParser build using vendor centroiding, MS2 output, and metadata export. It is a development build, so successful exit alone is insufficient: compare vendor metadata scan counts with independently parsed mzML counts; check unique scan identifiers, finite precursor/peak values, charge and activation fields, and binary-array lengths. Preserve errors and omissions. Search only after these checks pass, or classify the endpoint as unmeasurable with the available conversion. Source-file byte counts and local SHA-256 receipts establish transfer integrity; no publisher checksum was supplied in the archive inventory.

## Fixed search settings

Use fully tryptic digestion, up to two missed cleavages, 7–35 residues and precursor peptide masses of 600–5,000 Da. These broad search settings contain the four previously fixed targets (which have at most one missed cleavage). Use a 10 ppm precursor window, and search isotope offsets 0, +1 and +2. The deposited experiment uses 10 ppm, although the general paper states 20 ppm; preserve both. For high-resolution fragment spectra use Comet's documented 0.02-Da bin width, offset 0 and flanking bins; bin width is not the old pipeline's 0.05-Da fragment tolerance.

Apply fixed carbamidomethyl C (+57.021464), variable oxidation M (+15.994915), phosphorylation STY (+79.966331), peptide-N-terminal Q cyclization (−17.026549), and protein-N-terminal acetylation (+42.010565), with at most four variable modifications per peptide. The first three variable modifications occur in the deposited SEQUEST settings; protein-N-terminal acetylation also appears in the parallel Mascot settings. Permit initial methionine clipping. Use b/y fragments, water/ammonia neutral-loss scoring, a minimum of ten peaks, and precursor removal within 1.5 Da. Retain default Comet intensity processing; do not reproduce the old pipeline's top-six-peaks filter or confuse its total-intensity threshold with a per-peak threshold. These are declared reanalysis choices, not an exact reproduction of the original search.

Use eight search threads and batches of at most 5,000 spectra, within the 35-GB local-storage budget. If a technical failure requires a change, timestamp the repair and preserve the failed configuration; do not tune settings against target matches. Record unsearched spectra and all failures. Qualify the installed search engine with generated spectra of known toy peptides and modifications plus a decoy example before using public data. Synthetic recovery is a software check, not experimental detection or a calibrated limit of detection.

## Error control and interpretation

Retain the best target–decoy competitor per spectrum/charge query and the first five reported assignments for later competing-sequence inspection. Count ties at a common threshold. Rank best assignments by Comet expectation value and calculate the conservative cumulative estimate `(decoy wins + 1) / target wins`, capped at 1, then monotone q-values. A spectrum searched at more than one assumed charge must not become multiple accepted independent observations; retain the best expectation value per file/scan, with score ties containing a decoy treated conservatively. Calculate both spectrum and unique unmodified I/L-equivalent peptide summaries. Primary background reporting uses q ≤ 0.01; report counts before and after filtering.

All four fixed target strings and their I/L equivalents must be looked for among all reported ranks, irrespective of global q-value. Preserve their scores, modifications, matched fragments and competing assignments. Do not apply the global 1% estimate as proof that the small novel class has 1% error. With four targets and overlapping sequences, a well-powered novel-class error estimate is unavailable; report this explicitly. Any nominated candidate requires independent fragment matching and an explicit comparison with the best ordinary sequence competitor. Candidate-only or targeted rescoring cannot replace competition with the full frozen database. No discovery is established from a single shared/nested peptide.

Report ordinary UBASH3A peptide coverage as a measurement-context check. Distinguish peptides shared by reference and conditional proteins from those distinguishing the proposed ending. Repeated injections and nested peptides do not supply independent biological replication. A missing candidate match is a nondetection in these files under these settings, not absence of the protein, RNA, splice event or physiological function. Neither protein detection nor nondetection establishes NMD escape, PSC causality or a clinical intervention.

Method references: [Comet high-resolution binning](https://pmc.ncbi.nlm.nih.gov/articles/PMC4607604/), [internal decoys](https://uwpr.github.io/Comet/parameters/parameters_202301/decoy_search.html), [variable modification syntax](https://uwpr.github.io/Comet/parameters/parameters_202301/variable_mod01.html), and [isotope handling](https://uwpr.github.io/Comet/parameters/parameters_202401/isotope_error.html). Exact numerical settings are retained in the frozen parameter file.
