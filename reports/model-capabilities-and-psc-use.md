### Provider capabilities are not account entitlements

- **AlphaGenome:** the pinned client targets gRPC `gdmscience.googleapis.com:443`. `output_metadata(HOMO_SAPIENS)` is the appropriate first authenticated check. `ModelVersion.ALL_FOLDS` and `FOLD_0`–`FOLD_3` are selectors, not exact server-weight identifiers. ALL_FOLDS is not a held-out test. Previous manifests state that no server build identifier was exposed.
- **Lengths:** exactly **16,384; 131,072; 524,288; 1,048,576 bp**. The misleading-looking constant `SEQUENCE_LENGTH_100KB` means 131,072, not 100,000. Human requests use the reference build **GRCh38.p13**; gene scoring uses the model's GENCODE v46 annotation. Preserve separate Ensembl release-116 annotations.
- **Methods:** `predict_sequence`, `predict_interval`, and `predict_variant` return tracks; `score_variant` returns defined variant-effect summaries; `score_interval` returns interval summaries; `score_ism_variants` expands specified substitutions. The pinned client allows **20 scorers per request** and chunks ISM intervals at **10 bp**. These are client limits, not an account rate allowance. ISM is not authorized by this audit.
- **Outputs:** RNA-seq, ATAC, DNase, CAGE, PRO-cap, histone/TF ChIP, splice sites, splice-site usage, splice junctions and contact maps are supported classes. Exact resolution and returned axes must be read from each output, not assumed equal. The historical [human metadata inventory](../config/prkd2-mechanism-model-metadata.json) records raw track counts of 667 RNA, 167 ATAC, 305 DNase, 546 CAGE, 12 PRO-cap, 1,116 histone, 1,617 TF, 4 splice-site, 734 splice-usage, 367 junction and 28 contact-map tracks. **These counts were not refreshed here.**
- **Existing PSC scoring:** the pilot uses `RNA_SEQ`, `RNA_SEQ_ACTIVE`, `SPLICE_SITES`; the PRKD2 runner adds `SPLICE_SITE_USAGE`, DNase/ATAC/CAGE/histone effects and active scores. Direct UBASH3A REF/ALT splice tracks require `predict_variant`, not interpretation of a gene-wide unsigned maximum as a junction direction. Historic CD4 RNA assays disagree for some measured associations. The frozen monocyte selection has no ATAC track; missing tracks are not zero effects. There is no established PSC or IL-17A organoid response context.
- **Atlas:** `atlas.atlas.create(api_key)` supplies precomputed-variant lookups, not an independent biological benchmark. No Atlas call was made. The provider describes the research API as free for noncommercial use, with **demand-dependent query rates**; no numeric account rate, daily allowance or remaining quota was confirmed. Output restrictions remain separate from the repository MIT license.
- **AF3:** current official documentation exposes `run_alphafold.py --json_path ... --model_dir ...`, with separate data-pipeline and inference stages. Inputs can include exact protein/DNA/RNA chains, modifications, ligands, bonds and explicit stoichiometry. The current README offers a direct parameter-download URL; it does **not** prove local weights or permission. Source code is Apache-2.0; the fetched weights terms restrict parameters/output to specified noncommercial organizational uses. This project's eligibility is unverified. Full databases can require about 1 TB; the documented reference setup uses an 80-GB A100/H100. CPU operation is also documented as much slower. The local 10-GB GPU has not been qualified for any input.
- **AF2:** official monomer/monomer-pTM/multimer inference remains a separate option. Code is Apache-2.0 and parameters CC-BY-4.0. Its documented reduced databases require 600 GB; full installation can reach 3 TB. Neither that stack nor ColabFold/MSA-service access is confirmed. No weights, databases or containers were downloaded.

## Ranked, falsifiable PSC questions — data first

These are proposed follow-ups, **not new results or an inference queue**. The small matched AlphaGenome comparison did not show consistent useful prioritization. Repeating it or scoring more loci merely because access becomes available is not justified.

### 1. Does rs1893592-C increase the exact +29 splice form in primary CD4 cells?

- **Exact DNA:** GRCh38 chr21:42,434,957 **A>C**; original 0-based half-open interval `chr21:[41910668,42959244)`. Canonical donor exon ends at 42,434,954; +29 retention is 42,434,955–42,434,983 inclusive. Correct model donor-track indices are 42,434,953 and 42,434,982 (0-based). Use the already frozen REF/ALT predictions first; do not repeat inference to change an unfavorable result.
- **Measured benchmark/control:** donor-resolved normal and exact +29 junction counts in the [CD4 experiment plan](../docs/ubash3a-cd4-analysis-plan.md), with verified genotypes, complete RNA structure and normal-junction/assay-recovery controls. Test the splice ratio separately from total RNA abundance. Prior blood association supports one direction provisionally; sparse public CD4 reads do not settle it.
- **Added model value / stop:** a fixed signed prediction supplies a falsifiable allele-effect expectation. A precise opposite or absent effect in a qualified assay refutes that context-specific prediction. Stop at inadequate coverage, uncertain full RNA identity or unmatched cell state; do not turn those failures into a biological null or infer protein survival.

### 2. Do the ETS2-region alleles explain measured cis-regulatory effects, rather than a broad macrophage program?

- **Exact DNA:** GRCh38 chr21:39,094,818 **G>A** (rs2836883) and chr21:39,096,912 **G>A** (rs4817988), tested individually. A proposed common 1-Mb window is `chr21:[38570529,39619105)`, containing both sites; it does not alter prior run windows. Do not transfer rs2836883's risk direction to rs4817988 or assume their phase. Any reporter/deletion comparison additionally requires the **exact published insert sequences/deletion endpoints**, which this audit has not reconstructed.
- **Measured benchmark/control:** preserve source MPRA allele effects and enhancer-deletion effects on ETS2 and neighboring genes; require an independent, assay-matched replication or qualified follow-up before calling model agreement validation. Include measured inactive inserts, reference alleles and non-ETS2 targets. Reuse published experiments as known positive controls, not held-out labels.
- **Added model value / stop:** a small, frozen sequence contrast could localize a proposed regulatory change after the measured effect is established. Wrong target/sign or no separation from measured controls would limit usefulness. Stop without exact assay sequences, informative tracks or qualified controls. **ETS2 RNA abundance, program activity and causal ETS2 action remain three distinct endpoints.** Structure prediction cannot resolve that distinction.

### 3. Only if an exact +29 UBASH3A protein is observed: does its replacement tail disrupt the phosphatase-like region?

- **Exact protein inputs:** [the existing FASTA](../data/derived/ubash3a-consequences/proteins.fasta), records `ENST00000319294.11__normal_A` (661 aa), `ENST00000319294.11__plus29_A` and `ENST00000319294.11__plus29_C` (536 aa each). File SHA-256: `9d70e151c3c91023da0e86f57f3e125306d665826abb3f6cd3b66985e29dc379`. The reference sequence hash exactly matches the public AFDB canonical sequence. Use **one unmodified chain, no ligand or partner**, unless experimental evidence specifies another composition. These conditional translations are not observed products. The alternative-ending T29 candidate is a different 482-aa hypothesis and must not be substituted.
- **Measured benchmark/control:** first identify full RNA and isoform-specific protein; then compare reference and confirmed product with a qualified folding/stability or domain-interaction assay. Ordinary UBASH3A and assay-positive controls are required. The completed public protein search lacked a qualifying ordinary UBASH3A control and cannot qualify the hypothetical product.
- **Added model value / stop:** AF2/AF3 could nominate a testable domain/interface change beyond the known sequence truncation. Require matched model settings and confidence/PAE inspection; a confident structure does not measure stability, activity or pathogenicity. **Stop now:** full +29 protein evidence and usable new-folding access are absent. If the observed sequence differs, freeze that sequence instead; never fill missing residues or partners by guesswork.
